تحديث الإصدار الخامس عشر

الجديد:
- دعم إيماءة الرجوع في أندرويد داخل صفحات التطبيق بدل الخروج مباشرة.
- الرجوع من الفيديو إلى قائمة المقاطع، ومن قائمة المقاطع إلى شاهد وتعلّم.
- الرجوع بين شاشات الألعاب والمستويات بشكل طبيعي.
- إعادة إرفاق manifest والأيقونات الجديدة لتجهيز إصدار APK الجديد.

مهم:
- ارفع الملفات الموجودة في هذه الحزمة إلى جذر GitHub بجانب index.html.
- لا تحذف مجلد api ولا مجلد .well-known.
- تغيير أيقونة التطبيق وشاشة تشغيل أندرويد يتطلب إنشاء APK جديد بنفس Package ID ومفتاح التوقيع القديم.
