تحديث الإصدار الرابع - قائمة التواصل وروابط المعلّم الصغير
===========================================================

ما الجديد:
- إضافة زر ثلاث نقاط أعلى الواجهة الرئيسية.
- إضافة تواصل مباشر عبر واتساب.
- إضافة قناة المعلّم الصغير على واتساب.
- إضافة روابط يوتيوب وفيسبوك وإنستغرام وتيك توك.
- إضافة مشاركة التطبيق عبر نافذة المشاركة في الهاتف.
- إضافة نافذة «عن التطبيق».
- تحديث التخزين المؤقت لضمان وصول النسخة الجديدة إلى التطبيق المثبّت.

طريقة التحديث:
ارفع الملفات الموجودة في هذه الحزمة إلى جذر مستودع GitHub على فرع main، بجانب index.html، ثم نفّذ Commit changes.
لا تحذف مجلد .well-known ولا ملف assetlinks.json.
