تحديث الإصدار السابع: الأقسام الرئيسية

ما الذي تغيّر؟
- أصبحت الواجهة الرئيسية تعرض بطاقتين كبيرتين فقط: الألعاب، وشاهد وتعلّم.
- بطاقة الألعاب تفتح صفحة مستقلة فيها ذاكرة الفواكه والحرف والحيوان.
- بطاقة شاهد وتعلّم تفتح صفحة مستقلة فيها جزء عم ويوميات عزّام.
- بعد اختيار القائمة تظهر المقاطع المنفصلة للاختيار.
- أزيلت الأزرار الصغيرة أعلى الصفحة نهائيًا.

طريقة الرفع:
1) ارفع الملفات الخمسة إلى جذر GitHub بجانب index.html.
2) وافق على استبدال الملفات الموجودة ثم Commit changes.
3) افتح index.html على GitHub وابحث عن: الإصدار السابع.
4) انتظر Vercel حتى يصبح Ready ثم أغلق التطبيق وافتحه.
