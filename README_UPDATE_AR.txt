تحديث الإصدار الثاني عشر — المعلّم الصغير

التغييرات:
1) محاولة ثابتة لقراءة أسماء فيديوهات يوتيوب عبر JSONP بدون API أو مفتاح.
2) بعد فشل المحاولات لا تبقى عبارة «جارٍ قراءة الاسم»؛ يظهر اسم احتياطي رقمي.
3) تغيير اسم الموقع وملف PWA إلى «المعلّم الصغير».
4) إضافة أيقونة المعلّم الصغير الجديدة بكل المقاسات.
5) إضافة شاشة بدء جديدة بشعار المعلّم الصغير وعزّام.

طريقة الرفع:
- ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر GitHub بجانب index.html.
- وافق على استبدال الملفات القديمة ثم Commit changes.
- لا تحذف مجلد .well-known.
- انتظر Vercel حتى يصبح Ready ثم أغلق التطبيق بالقوة وافتحه.

مهم:
اسم وأيقونة نسخة APK المثبتة على شاشة الهاتف جزء من ملف APK نفسه. ملفات الويب تحدّث الموقع وشاشة البدء الداخلية، أما الاسم والأيقونة في مشغل أندرويد فيحتاجان بناء APK جديد لاحقًا بنفس Package ID ومفتاح التوقيع القديم.
