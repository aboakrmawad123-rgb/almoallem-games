تحديث لعبة صيد الحرف - الإصدار 32
=================================

محتوى التحديث:
- إضافة لعبة جديدة باسم "صيد الحرف".
- المستوى الأول: سرعة هادئة، 10 حروف صحيحة للفوز.
- المستوى الثاني: سرعة أعلى وحروف متشابهة، 15 حرفًا صحيحًا للفوز.
- سلة قابلة للسحب يمينًا ويسارًا.
- 3 قلوب: التقاط حرف خاطئ ينقص قلبًا، وبعد 3 أخطاء تنتهي المحاولات.
- مرور الحرف الصحيح من دون التقاطه لا ينقص قلبًا.
- تغيير الحرف المطلوب بعد كل إجابة صحيحة.
- إضافة التسجيل الصوتي: "انتهت المحاولات، حاول مرة أخرى".

طريقة الرفع إلى GitHub:
1) ارفع الملفات التالية إلى جذر المشروع بجانب index.html:
   - index.html
   - script.js
   - service-worker.js

2) افتح مجلد audio في GitHub وارفع داخله:
   - letter-hunt-lose.wav

3) اعمل Commit وانتظر حتى يصبح نشر Vercel بحالة Ready.
4) أغلق التطبيق بالقوة وافتحه من جديد.

لا حاجة لإعادة رفع الصور أو بقية ملفات الصوت القديمة.
