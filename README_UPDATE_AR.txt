تحديث الإصدار الخامس - مكتبة الفيديو
===================================

ما الجديد:
- إضافة بطاقة «مكتبة الفيديو» إلى الواجهة الرئيسية.
- إضافة قائمة «جزء عم» داخل التطبيق.
- إضافة قائمة «يوميات عزّام» داخل التطبيق.
- تشغيل قوائم يوتيوب ضمن مشغّل مدمج دون تشغيل تلقائي.
- استخدام وضع الخصوصية المحسّن لمشغّل يوتيوب.
- إضافة زر احتياطي لفتح القائمة في يوتيوب عند الحاجة.
- إيقاف تشغيل الفيديو عند الرجوع إلى واجهة الألعاب.
- تحديث التخزين المؤقت لضمان وصول النسخة الجديدة إلى التطبيق المثبّت.

ملاحظة:
مشاهدة المقاطع تحتاج إلى اتصال بالإنترنت، بينما الألعاب تبقى متاحة دون إنترنت بعد تحميلها.

طريقة التحديث:
ارفع الملفات الموجودة في هذه الحزمة إلى جذر مستودع GitHub على فرع main، بجانب index.html، ثم نفّذ Commit changes.
لا تحذف مجلد .well-known ولا ملف assetlinks.json.
