تحديث الإصدار الرابع عشر — الربط الرسمي مع YouTube Data API

ما تم إصلاحه:
- أسماء المقاطع تأتي من YouTube Data API الرسمي عبر Vercel.
- مفتاح API يبقى سريًا داخل YOUTUBE_API_KEY ولا يظهر في ملفات GitHub.
- جلب قائمة جزء عم كاملة على عدة صفحات تلقائيًا.
- حفظ آخر قائمة ناجحة على الهاتف لاستخدامها عند ضعف الاتصال.
- إزالة شاشة التحميل الداخلية، لتبقى شاشة تحميل واحدة فقط من APK.

الرفع إلى GitHub:
1) ارفع إلى جذر المشروع:
   index.html
   script.js
   service-worker.js
   vercel.json

2) يجب وضع الملف youtube-playlist.js داخل مجلد اسمه api في المستودع، ليصبح المسار:
   api/youtube-playlist.js

على الهاتف إذا لم يكن مجلد api موجودًا:
- من جذر المستودع اختر Create new file.
- اكتب في اسم الملف: api/.keep
- اكتب أي كلمة صغيرة في المحتوى واضغط Commit changes.
- افتح مجلد api الجديد وارفع داخله youtube-playlist.js.
- يمكن ترك ملف .keep أو حذفه لاحقًا.

3) لا تضغط Redeploy قبل رفع الملفات. رفع الملفات وعمل Commit سيبدأ نشرًا جديدًا تلقائيًا ويقرأ متغير YOUTUBE_API_KEY الذي حفظته.
4) بعد أن تصبح حالة Vercel Ready، افتح التطبيق وتأكد أن الواجهة تعرض: الإصدار الرابع عشر.
