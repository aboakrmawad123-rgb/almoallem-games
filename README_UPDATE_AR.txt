تحديث أصوات التشجيع - الإصدار السادس عشر

الملفات المعدلة:
- index.html
- script.js
- service-worker.js

ما الجديد:
- صوت عربي عند الإجابة الصحيحة: أحسنت / رائع / ممتاز يا بطل.
- صوت عند المحاولة غير الصحيحة: حاول مرة أخرى.
- نغمة احتفال ورسالة صوتية عند إنهاء المستوى.
- زر داخل قائمة الثلاث نقاط لتشغيل أصوات التشجيع أو إيقافها.
- حفظ اختيار الصوت على الجهاز.
- نغمات احتياطية تعمل حتى لو لم يتوفر صوت عربي على الجهاز.
- تحديث رسالة واتساب إلى اسم المعلّم الصغير.

طريقة الرفع:
ارفع الملفات الأربعة إلى جذر GitHub بجانب index.html ثم Commit changes.
لا تحذف مجلد api ولا مجلد .well-known.
لا تحتاج إلى APK جديد لهذا التحديث.
