تحديث موقع Vercel مع الحفاظ على الرابط
======================================

المشروع الحالي أُنشئ باستخدام Vercel Drop.
Vercel Drop مناسب للرفع الأول، لكن كل Drop جديد ينشئ مشروعًا جديدًا ولا يحدّث المشروع القديم مباشرة.

للحفاظ على نفس الرابط في التحديثات القادمة، اربط المشروع الحالي بمستودع GitHub من إعدادات Git في Vercel.
بعد الربط، كل تحديث ترفعه إلى المستودع ينشر تلقائيًا على نفس المشروع والرابط.

لا تحذف المشروع الحالي أو النطاق الحالي.
